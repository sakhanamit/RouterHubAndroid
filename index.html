Core Capabilities

Engineered for Complete Network Visibility

RouterHub packs desktop-grade networking tools into an intuitive, touch-first Android experience.

Multi-Router Management

Detect gateways automatically, manage multiple router profiles (home, office, mesh nodes), and quickly access web configuration portals in an embedded WebView.

  • ✓ Encrypted Credentials Store
  • ✓ Custom Desktop User-Agent Toggles

Subnet Device Scanner

Perform high-speed multi-threaded scans of your entire /24 subnet to identify every connected host, vendor OUI, and active service.

  • ✓ Kernel ARP Table Inspection
  • ✓ Port Banner & HTTP Title Parsing

Automated Security Auditor

Evaluates router security against unencrypted HTTP interfaces, open risky management ports (Telnet, FTP, SMB), weak default login risks, and WPS/UPnP vulnerabilities.

  • ✓ 0–100 Health Rating Scale
  • ✓ Actionable Hardening Advice

RouterHub is engineered specifically for privacy-conscious users and network engineers. All network discovery, port scans, and credential storage are strictly isolated to your local device hardware.

• No cloud server dependencies
