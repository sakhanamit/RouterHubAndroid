Core Capabilities

Engineered for Complete Network Visibility

RouterHub packs desktop-grade networking tools into an intuitive, touch-first Android experience.

Multi-Router Management

Detect gateways automatically, manage multiple router profiles, and quickly access web configuration portals in an embedded WebView.

  • ✓ Encrypted Credentials Store
  • ✓ Custom Desktop User-Agent Toggles

Subnet Device Scanner

Perform high-speed multi-threaded scans of your entire /24 subnet to identify every connected host with protocol badges and color-coded latency.

  • ✓ Categorized Device Identification
  • ✓ Protocol Badges & Response Times

Automated Security Auditor

Evaluates router security against unencrypted HTTP interfaces, open risky management ports (Telnet, FTP, SMB), weak default login risks, and WPS/UPnP vulnerabilities.

  • ✓ 0–100 Health Rating Scale
  • ✓ Dedicated Re-run Security Rescan
